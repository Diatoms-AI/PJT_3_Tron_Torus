### 1. The Pulse-to-Sense Circuit Diagram

This design uses a **High-Side SCR** for the discharge and a **High-Speed Signal Relay or MOSFET switch** to divert the bifilar coil to the "Sense" line.

**Key Components:**

- **Storage Cap ($C_1$):** 20µF–100µF (450V Rated).
    
- **The Hammer ($Q_1$):** A high-current SCR (e.g., BT151 or similar) to dump the charge into the bifilar coil.
    
- **The Bridge ($D_{fly}$):** An ultra-fast recovery diode to catch the inductive kickback so it doesn't cook the SCR.
    
- **The Gate ($K_1$):** A high-speed reed relay or a pair of back-to-back MOSFETs to "listen" to the coil only after the pulse is dead.

### 2. Microcontroller Timing Logic (Arduino/ESP32)

The timing is critical. You must ensure the SCR is fully "Off" (current has dropped below holding level) before you connect your sensitive measurement circuit.

C++

```
const int triggerPin = 2; // Pin to SCR Gate
const int sensePin = 3;   // Pin to Sense Switch (Relay/MOSFET)

void setup() {
  pinMode(triggerPin, OUTPUT);
  pinMode(sensePin, OUTPUT);
  digitalWrite(sensePin, LOW); // Measurement circuit ISOLATED
}

void runExperiment() {
  // 1. DISCHARGE (The Kick)
  digitalWrite(triggerPin, HIGH); 
  delayMicroseconds(50); // Pulse duration
  digitalWrite(triggerPin, LOW);
  
  // 2. SETTLE (The Blanking Interval)
  // Wait for the magnetic field to collapse and SCR to turn off
  delayMicroseconds(200); 

  // 3. SENSE (The Listen)
  digitalWrite(sensePin, HIGH); // Connect Bifilar to Scope/ADC
  
  // Keep sensing for 500ms to capture the Sphericon's Z-axis spin-down
  delay(500); 
  
  digitalWrite(sensePin, LOW); // Re-isolate for next test
}
```
