This Python script will allow you to take the recorded data from your "Pulse-Sense" circuit and extract the geometric signature of the Limaçon cage. By using a **Fast Fourier Transform (FFT)**, we can separate the Sphericon’s slow Z-axis rotation from the rapid 11-loop inductive pulses.

### 1. The Harmonic Analysis Script

This script looks for the "Geometric Locking" signature. If the Limaçon geometry is successfully creating a vortex, you will see a dominant spike at the 11th harmonic of the rotation frequency.

Python

```
import numpy as np
import matplotlib.pyplot as plt
from scipy.fft import fft, fftfreq

# --- Load your Oscilloscope/Arduino CSV Data ---
# Format: Time(s), Voltage(V)
data = np.genfromtxt('vortex_echo.csv', delimiter=',', skip_header=1)
time = data[:, 0]
voltage = data[:, 1]

# --- Sampling Parameters ---
N = len(time)
T = time[1] - time[0]  # Sampling interval

# --- Perform FFT ---
yf = fft(voltage)
xf = fftfreq(N, T)[:N//2]
amplitude = 2.0/N * np.abs(yf[0:N//2])

# --- Identify Peaks ---
peak_index = np.argmax(amplitude)
fundamental_freq = xf[peak_index] # This is the Z-axis RPM (in Hz)
vortex_harmonic = fundamental_freq * 11

# --- Plotting ---
plt.figure(figsize=(10, 5))
plt.plot(xf, amplitude, color='cyan')
plt.axvline(x=fundamental_freq, color='gold', linestyle='--', label='Z-Spin (Fundamental)')
plt.axvline(x=vortex_harmonic, color='red', linestyle='--', label='11-Loop Harmonic (Vortex)')
plt.title("FFT Analysis: Limaçon-Sphericon Pulse Signature")
plt.xlabel("Frequency (Hz)")
plt.ylabel("Magnetic Intensity")
plt.xlim(0, fundamental_freq * 20) # Focus on relevant harmonics
plt.legend()
plt.grid()
plt.show()
```
